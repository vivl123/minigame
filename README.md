## Запуск
Откройте main.py в PyCharm или выполните:

```bash
python main.py
```

В macOS обычно используется `python3 main.py`.
Нужен Python с Tkinter. Установка пакетов через pip не требуется.
Если Tkinter отсутствует, установите сборку Python с поддержкой Tcl/Tk.

## Как играть
Введите целое число от 1 до 100 и нажмите «Проверить».
Следуйте подсказкам. После победы нажмите «Новая игра».
В меню доступны новая игра, выход, правила и два размера окна.
Окно также можно растягивать мышью.

## Файлы
- main.py — весь код, пять функций, без классов.
- prototypes.drawio — два редактируемых статических прототипа; откройте в draw.io.
- prototype_game.png, prototype_settings.png — изображения прототипов.
- Lab3_Arkhipov.docx — отчёт с листингом и 20 ответами к защите.

## История Git
Рядом с папкой проекта находится guess_number.bundle с локальной историей Git.
Чтобы получить рабочую копию с историей, выполните из папки с bundle:

```bash
git clone guess_number.bundle guess_number_git
cd guess_number_git
python main.py
```

Для публикации создайте пустой репозиторий в своём аккаунте GitHub.
Затем подставьте его настоящий адрес вместо YOUR_REPOSITORY_URL:

```bash
git remote add origin YOUR_REPOSITORY_URL
git push -u origin master
```

Публикация не выполнена. Отчёт содержит полный листинг вместо ссылки.
